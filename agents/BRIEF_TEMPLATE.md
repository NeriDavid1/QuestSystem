# Questline brief template

## Scope and readiness

- User request and destination: text / local source / hosted draft / published revision.
- Age/readiness, known English, assumptions, requested length.
- Observable outcomes, prerequisite ladder and independent success evidence.

## Kingdom story

- Two short premises; selected premise and reason.
- NPC motive, problem, stakes, complication/discovery, resolution.
- Registered speakers/locations/stations; proposed characters clearly labeled.
- What each task changes; which events are dialogue-only.

## Dialogue and closure

## Dependencies and review

- Verified asset paths/IDs or explicit missing status.
- Initial support, purposeful repetition, reduced-support check and transfer.
- Game range, answer occurrences, valid indices and distractor rationale.
- Creator source/checks; QA content/import/runtime/publication statuses.
